# 医疗文件处理工具

项目包含视频拼接、视频采帧、文件清洗和文件重命名四大功能。

## 功能特性

### 1. 视频拼接
- 使用FFmpeg

### 2. 视频采帧
- 可自定义采样间隔（按帧数或秒数）

### 3. 文件清洗
- 识别并处理孤立的JPG文件

### 4. 文件重命名
- 按数字顺序批量重命名文件
- 支持自定义起始编号和位数
- 可指定文件范围

### 运行
FFmpeg下载地址
```bash
https://ffmpeg.org/download.html
```

运行

```bash
pip install -r requirements.txt
python main.py
```
